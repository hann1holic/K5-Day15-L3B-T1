# Nền trang đầu

Bốn cảnh đổi vòng tròn (`../../backdrop.js`), tải từ Wikimedia Commons. Ảnh trong thư mục này đã được **chỉnh sửa**
(cắt, đổi màu, ghép, chuyển sang WebP 2560×1440). Tia lửa, tuyết, sương, chớp và mắt sói sáng là hiệu ứng viết
bằng mã, không nằm trong ảnh.
